# SPOMINiii (spomini.si) — Website Features

**What it is:** A Slovenian web app combining a "photo album with descriptions" and a search engine for events, places, and their organizers/publishers ("bases" = records for events/locations). Available in 7 languages (Slovenian, English, German, Italian, French, Spanish, Croatian).

## Search / Discovery (no login needed)

- **Search bases** — filter by country/state, place, category > subcategory (e.g. Sport > Cycling, Sport > Volleyball, Sport > Chess, Culture > Music, Turism > Places), recurring vs. one-off, and language
- **Search by code** — look up a specific base by its ID code
- **Latest bases feed** — homepage list of newest entries, with "show more"
- **Publisher search** — find organizers/advertisers by name
- **Personal user search** — find other registered users (logged-in only)
- Newsletter signup (email + language preference)

## Personal (Free) Accounts

- Create records combining text and images from reusable "line blocks"
- "Take" (copy) an existing base's record and customize it with your own blocks
- View/manage your own records
- Connect with other users ("viewing" relationships) and share personal records with them
- View records other users have shared with you
- Recommend bases/publishers to others
- Maintain wishlists of desired bases/publishers
- Comment on bases and on other users' records
- Publish your own records publicly
- Upload images and PDF documents to a record

## Publisher/Advertiser Accounts (Business, Partly Paid)

- Present events and places by creating custom "bases"
- Advertise using those custom bases (logo, name, links)
- Upload images and PDFs for a base
- Access to the same search tools as personal accounts

## Other Site Features

- Google Maps integration for location data
- Google reCAPTCHA on registration
- Cookie consent banner + GDPR-based data/privacy documentation
- Informational pages: Usage Instructions, Terms of Use, Data Collection/Protection, Cookie Usage, User Copyrights, Price List, About the App, Employment Opportunity

## Account & Pricing Notes

- Use without registration is free; registration for any account type is free
- Personal accounts are free, except charges for map-based location entries and larger storage
- Publisher-advertiser accounts are partly free / partly paid (search engine use is free)
- Users over 15 years old only
- Account deletion available at any time (publisher accounts: minimum 1-month process)
